## ✨ Features & User Experience

### 1. 🎡 Interactive 3D Chef's Showcase Carousel
- Dynamic 3D perspective stage with depth rotation and card spotlighting.
- Auto-play rotation every 3.5 seconds with pause-on-hover.
- Click-to-focus on any card and animated navigation dots.
- Touch-swipe support for seamless mobile browsing.

### 2. 🍱 Continuous Drifting Food Rails (Infinite Scroller)
- Dual continuous horizontal drifting rails showcasing signature delicacies:
  - *Royal Chicken Makhni Handi* (Clay Pot Royalty)
  - *Signature Double Smash Burger*
  - *Heritage Charcoal Seekh Kebabs & Boti*
  - *Prime Sizzling Tenderloin Steak*
  - *Famous Golden Broast Chicken*
  - *Artisan Wood-Fired Pizza*
  - *Decadent Chocolate Molten Lava Cake*
- Smooth pause-on-hover for effortless inspection.

### 3. 🔍 Interactive Dish Quick-View & Order Modal
- High-definition dish previews with chef preparation notes.
- Portion selector (*Standard Serves 1-2* / *Family Size Serves 3-4*).
- Direct one-tap ordering hotline call (+92 42 111 100 678).

### 4. ⭐ Dynamic Customer Feedback System
- Interactive 5-star rating matrix across 4 key dimensions:
  - Food Quality & Taste
  - Service & Hospitality
  - Ambiance & Atmosphere
  - Cleanliness & Hygiene
- Celebratory success modal upon submission.

### 5. 📱 Fully Responsive Mobile Navigation
- Glassmorphic fixed navigation with scroll detection.
- Animated mobile hamburger button and slide-out navigation drawer.

- **Animations**: CSS3 3D Transforms, AOS (Animate On Scroll), Keyframe Animations
- **Typography**: Google Fonts (*Playfair Display* + *Outfit*)
- **Hosting**: GitHub Pages
